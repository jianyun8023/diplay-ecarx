本版适用于 2021 款领克 01／753 车机系统（Android 9），可直接覆盖安装同签名的 v134 或台架版本。

主要变化

• 应用内更新：「设置 › 关于」可检查更新并显示更新说明。下载来源可选「自动」（依次尝试上次可用来源、GitHub 直连、ghfast.top、gh-proxy.com）、固定来源或自定义加速站。下载后核对 SHA-256，并确认安装包与本应用的包名和签名一致才会安装。v134 及更早版本没有这个功能，本次需手动安装。
• MFi 认证身份保存在车机上：公开包不含认证身份，覆盖升级会继续使用已有身份。「设置 › 高级 › MFi 证书与签名目标」可查看身份状态，也可导入 identity.pk8 与 certificate.p7b：应用先确认两者匹配再替换，不匹配则保留原身份。
• 熄火下车后再点亮屏幕可自动重连：等待车机恢复蓝牙和热点，宿主重建后也能继续等待。
• 暂停音乐改为两个开关（设置 › 音频 › 车机媒体集成，默认关闭）：打开主驾车门时暂停、车辆熄火时暂停。
• 日夜模式精简为 5 项，默认「跟随车机」；「跟随车外光线」使用车身光线传感器，冷启动时即正确。
• 诊断报告补充屏幕、整车电源、车门与媒体命令记录，以及日夜模式来源与耗时。

安装与使用提醒

• 下载 DiPlay-release.apk；SHA256SUMS.txt 用于核对文件；update.json 供应用内更新读取。
• 正式包由 GitHub Actions 使用现有平台证书签名，不内置 MFi 连接认证文件。覆盖安装会保留已有身份；请不要卸载或清除数据。身份丢失时可在设置中重新导入。
• 熄火后自动重连、身份保留与导入已在小米 8 台架验证；日夜模式冷启动与应用内更新仍待实车复测。
