# DiPlay · 領克 01 CarPlay

[简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [English](README.md#english)

在領克車機上使用 iPhone 的導航、音樂、Siri 和通話。目前主要適配 **2021 款領克 01**，其他車型及系統版本尚未確認。

> 這是開發版說明。新增的方向盤語音鍵短按喚起 Siri 功能仍在實車驗證中。

## 可以做什麼

- 在中控使用 CarPlay 導航、播放音樂及接打電話。
- 在車機支援的情況下，將導航提示、車道資訊顯示到儀表和 HUD。
- 顯示正在播放的歌曲與封面，使用方向盤按鍵控制播放、暫停和切歌。
- 使用車機熱點連接 iPhone，並在熱點啟動失敗時嘗試恢復。

介面支援簡體中文、繁體中文和英文，可跟隨系統語言。

## 安裝與更新

請先確認安裝包適用於自己的車機，並具備連接 iPhone 所需的認證設定。一般原始碼建置套件可用於查看介面，連接前仍需設定認證。

1. 將安裝包複製到車機或 USB 隨身碟，透過檔案管理員安裝。
2. 更新時優先覆蓋安裝，保留既有設定。如果提示無法覆蓋，請先備份設定與診斷報告，再處理舊版。
3. 首次開啟後，依照畫面提示完成權限與連接設定。

開發測試包與一般安裝包的設定不會自動互通。測試前結束其他投屏應用程式的連接，避免同時使用同一台 iPhone。

## 連接 iPhone

**無線連接**：在連接設定中選擇車機熱點、Wi-Fi Direct 或既有 Wi-Fi，依照畫面提示完成手機配對與網路連接。不要同時執行其他投屏工作階段。

**USB 連接**：使用支援資料傳輸的線材和車機資料接口，依照提示允許存取，並在 iPhone 上確認信任。目前 USB 連接仍有未解決的問題。

熱點啟動失敗時，應用程式會嘗試切換 Wi-Fi 並恢復熱點一次。過程中，其他已連接的無線裝置可能暫時中斷。

## 常用設定

| 想做什麼 | 在哪裡設定 |
| --- | --- |
| 選擇連接方式、手機和車機熱點 | 連接 |
| 調整畫面大小、顯示效果與影格率 | 顯示 |
| 調整音樂與導航聲音 | 音訊 |
| 開啟儀表、HUD 導航提示及調整可視區域 | 導航 |
| 設定方向盤按鍵 | 車輛 |
| 儲存問題報告 | 診斷 |

**音樂走 CarPlay**：可按需開啟藍牙媒體讓位，讓音樂使用 CarPlay，同時保留原車電話功能。它與關閉整個車機藍牙是不同選項。

**儀表畫面**：全螢幕鏡像會覆蓋儀表上的導航提示與媒體卡片，請只在確有需要時開啟。

**Siri**：連接 CarPlay 後，短按方向盤語音鍵可喚起 Siri。長按仍交給原車處理，斷開後恢復原車按鍵功能。測試時請關閉 HY 的語音鍵接管，避免同一按鈕重複回應。

## 目前需要留意的問題

- USB 首次連接與重連仍有問題，早期某次連接成功不代表所有情境都已正常。
- iPhone 關閉再開啟藍牙後，部分情況仍需手動選擇車機連接。
- 熱點恢復與語音鍵回應會受車機系統影響，新版本仍需在實際車輛上確認。

不需要依照舊版說明一律關閉手機藍牙或停用系統語音助理。遇到問題時，先記錄現象並儲存報告。

## 遇到問題

重現問題後，開啟 **設定 → 診斷 → 儲存診斷報告**。儲存提示會顯示檔案位置，也可選擇其他位置。

回饋時請說明車型、車機系統版本、iPhone 型號與 iOS 版本、連接方式，以及具體操作和發生時間。
附上完整報告及必要截圖，不要提供熱點密碼或認證檔案。
