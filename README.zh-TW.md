# DiPlay · 領克 01（2021 款）/ ECARX · dev

本頁對應 **`dev` 分支**。完整功能、建置與歷史說明見 [README.md](README.md)。
目前已合併上游 **v0.2.22**，應用版本沿用 **0.2 / versionCode 101**。

- **共同功能**：ECARX MediaCenter 媒體控制、導航/HUD/車道、儀表可視區域、藍牙媒體讓位、HiCar 控制及統一熱點恢復。
- **最新回饋**：媒體 service 與導航/HUD 正常，原有 Siri 擷取路徑正常；USB 最新測試仍有問題，不能沿用早期「測試 OK」作完整驗收。
- **DEV 差異**：連線期間語音鍵短按觸發 Siri、去重、背景保持與斷線釋放，以及按鍵 SDK 釋放修正、更多連線診斷。`release` 尚未合入短按接管。
- **DEV 已清理**：方案 B 通訊擷取實驗、本機錄音自檢、獨立媒體探測面板及舊「僅長按」選項；保留原擷取路徑與一般錯誤報告。Release 未引入方案 B 或自檢，仍保留舊長按選項。
- **熱點恢復**：Android 9 明確失敗後，按 Wi-Fi 實際狀態完成開啟→關閉，再重試熱點一次。不更改名稱或密碼，但會中斷其他無線裝置；仍待實車確認。
- **驗收邊界**：新組合、Siri 短按、USB 與自動重連需實車回歸；不以軟體測試或歷史領克 05 紀錄代替。
- **環境與語言**：使用者報告為 Android 9 / API 28、MSM8996、`dcy11_a1`；介面提供英文、簡體中文、繁體中文與跟隨系統。

建置環境為 JDK 25、Gradle wrapper 9.5.0、SDK 37.0、Build Tools 36.0.0；最低 API 24 只代表安裝下限。
Source-only 套件不含認證身分，缺少既有認證前置時不能驗證完整 CarPlay 建連。
同包名與簽名可覆蓋安裝；變更簽名前先備份設定和報告，不以清除資料作常規重連方式。
