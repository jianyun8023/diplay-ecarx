# DiPlay · 領克 01 CarPlay

正式環境：Android 9（API 28）／753／820A，使用現有平台簽章。應用程式內不使用 ADB，APK 僅含 ARM64／ARMv7；其他 Android 版本僅用於除錯。見 [權限清單](docs/ADB_AND_PLATFORM_PERMISSIONS.zh-CN.md)。

[简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [English](README.md#english)

DiPlay 讓你在領克車機上使用 iPhone 的導航、音樂、Siri 和通話。適配**億咖通車機 753 版本**（領克高通 820A 平台），目前於 **2021 款領克 01** 驗證；同平台的 753 車機理論上通用。

連接、日常設定和排錯，見 [車主使用說明（含設定圖）](docs/USER-GUIDE.zh-CN.md)。功能細節與驗證範圍見 [詳細說明](docs/FEATURES.zh-CN.md)（兩份皆為簡體中文）。

各文件開頭標註其適用版本：車主使用說明對齊 v142 車測包，詳細說明以 v134 為基線。導航聲音、自動熱點保護、開機服務與短按 Siri 的新實作仍待實車複測。

| 功能 | 需要開啟的設定 |
| --- | --- |
| 儀表和 HUD 導航提示 | **設定 → 導航 → 億咖通導航**，開啟「HUD／儀表導航提示」 |
| 車道指引 | 隨「HUD／儀表導航提示」輸出手機提供的有效車道，無需獨立開關 |
| 歌曲資訊和封面 | **設定 → 音訊 → 車機媒體整合**，選擇「DiPlay 直接接管」或「HY 代理」，歌曲資訊隨所選後端輸出 |
| 日夜模式跟隨車輛 | **設定 → 顯示 → 顯示方式與效能**，把「CarPlay 日夜模式」設為「跟隨車輛」 |
| 音樂走 CarPlay、保留藍牙電話 | **設定 → 音訊 → 音訊路由 → 聲音異常排查**，開啟「CarPlay 期間停用藍牙媒體」，關閉「透過車輛藍牙播放 CarPlay 音訊」 |
| 導航壓低音樂或共同播報 | **設定 → 音訊 → 音訊路由**，預設開啟「導航聲音跟隨 iPhone 和車機」；手機地圖選播報方式，車機調導航音量，修改開關後重新連線 |
| 無線連接 | 在連接設定中選擇車機熱點、Wi-Fi Direct 或既有 Wi-Fi，依照提示完成設定 |
| 開機自動連接 | **設定 → 連接 → 自動連接**，開啟兩項啟動開關，選無線與目標 iPhone；車機熱點需儲存設定並按需開啟自動熱點 |
| 自動熱點保持穩定 | 在 **設定 → 連接 → 連接設定** 選擇車載熱點，開啟自動熱點後預設「保持車機 Wi-Fi 關閉」；需要車機連其他 Wi-Fi 時關閉此項 |
| 方向盤語音鍵叫 Siri | **設定 → 車輛 → 方向盤按鍵**，開啟「方向盤喚醒 Siri」；直接接管模式選短按／長按，HY 代理模式選 155/156 或 312/303 |

**文中「HY」指 HYWebview（`com.hyphp.hywebview`），適配版本 3.6.1。** DiPlay 直接接管模式下，請關閉 HY 的媒體接管及同一語音鍵的方控接管；HY 代理模式請在兩邊選擇相同的 Siri 模擬按鍵。

**方向盤 Siri**：在「設定 → 車輛 → 方向盤按鍵」用總開關開啟或關閉。DiPlay 直接接管時選擇短按／長按；HY 代理時選擇 155/156 或 312/303，並在 HYWebview 的方向盤設定裡配置相同模擬按鍵。原有 Siri 橋接入口繼續可用，不受按鍵總開關影響。不提供按鍵學習；未連接 CarPlay 或通話中不接管。

只顯示導航提示和歌曲資訊時，保持「整屏鏡像到儀表」關閉。修改設定後，依照畫面提示重新連接。

**高德地圖顯示到儀表，需要 iPhone 使用 iOS 17.4 或更新版本。**

自動熱點會關閉車機連接其他 Wi-Fi 的功能，iPhone 的 Wi-Fi 仍須開啟。關閉保護項時，若 CarPlay 正在使用熱點，車機 Wi-Fi 延至下次車輛啟動恢復。開機設定齊全時可直接進入 CarPlay，v134 會先等原車桌面服務，最多 5 秒。

建議首次使用無線配對。如果本車 CarPlay 紀錄首次透過 USB 建立，改無線前須在 iPhone 刪除本車紀錄，再先無線配對。已設定無線時，插 USB 預設不接管；開關在 **連接 → 自動連接**。v122 的插線兩條路徑已實車確認，USB 卡頓與取消授權後的恢復仍未解決。遇到異常，請到 **設定 → 診斷 → 儲存診斷報告**。

同套件名稱、同簽章且版本號不低於已安裝版本時覆蓋升級，保留設定；Actions 公開發佈包不內建 MFi 認證，全新安裝或清除資料後需另行設定。不要先解除安裝。
