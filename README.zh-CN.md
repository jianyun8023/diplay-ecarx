# DiPlay · 领克 01（2021 款）/ ECARX · dev

本页对应 **`dev` 分支**。完整功能、构建与历史说明见 [README.md](README.md)。
当前已合并上游 **v0.2.22**，应用版本沿用 **0.2 / versionCode 101**。

- **共同功能**：ECARX MediaCenter 媒体控制、导航/HUD/车道、仪表可视区域、蓝牙媒体让位、HiCar 控制及统一热点恢复。
- **最新反馈**：媒体 service 和导航/HUD 正常，原有 Siri 采集路径正常；USB 最新测试仍有问题，不能沿用早期“测试 OK”作为完整验收。
- **DEV 差异**：连接期间语音键短按触发 Siri、去重、后台保持及断连释放，以及按键 SDK 释放修正和更多连接诊断。`release` 尚未合入短按接管。
- **DEV 已清理**：方案 B 通信采集实验、本地录音自检、独立媒体探测面板及旧“仅长按”选项；保留原采集路径和常规错误报告。Release 未引入方案 B 或自检，仍保留旧长按选项。
- **热点恢复**：Android 9 明确失败后，按 Wi-Fi 实际状态完成开启→关闭，再重试热点一次。不改名称或密码，但会断开其他无线设备；仍待实车确认。
- **验收边界**：新组合、Siri 短按、USB 及自动重连需实车回归，不以软件测试或历史领克 05 记录替代。
- **环境与语言**：用户报告为 Android 9 / API 28、MSM8996、`dcy11_a1`；界面提供英文、简体中文、繁体中文和跟随系统。

构建环境为 JDK 25、Gradle wrapper 9.5.0、SDK 37.0、Build Tools 36.0.0；最低 API 24 只表示安装下限。
Source-only 包不含认证身份，缺少既有认证前置时不能验证完整 CarPlay 建连。
同包名、同签名可覆盖安装；换签名前先备份设置与报告，不以清数据作为常规重连办法。
