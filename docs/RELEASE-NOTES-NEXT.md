# DiPlay ECARX release notes

The current ECARX release is **[v134](https://github.com/jianyun8023/diplay-ecarx/releases/tag/v134)**, based on upstream DiPlay 0.2.22, with Android versionCode 134.

- [Owner's guide](USER-GUIDE.zh-CN.md) (Simplified Chinese): connection, everyday settings, troubleshooting and upgrades, with six v134 settings screenshots.
- [Detailed feature guide](FEATURES.zh-CN.md): behavior, prerequisites and remaining vehicle checks.
- [Changelog](../CHANGELOG.md): changes since v122, including navigation sound, automatic hotspot protection, startup and wireless recovery.

Amap's instrument-cluster map requires **iOS 17.4 or later** on the iPhone. Navigation sound, hotspot protection, startup Siri and cluster visibility still need vehicle testing.

Public release APKs are platform-signed and contain no MFi credentials. Update in place with the same package and signature; a fresh install or cleared data needs credentials supplied separately.

Historical upstream changes are recorded in the [0.2.22 release notes](RELEASE-NOTES-0.2.22.md).
