# DiPlay v147 / v148 车测说明

更新日期：2026-11-11　适用：2021 款领克 01，753 车机（Android 9）

这份说明告诉你这两个测试版改了什么、上车前要打开哪些开关、按什么顺序测，以及测完要把什么发回来。整轮测试大约 30 分钟，大部分在正常开车时顺带完成。

## 一、这两版改了什么

**v148 包含 v147 的全部内容**，直接装 v148 即可。

### v147：修问题，日常体感基本不变

| 改了什么 | 你可能会注意到 |
| --- | --- |
| 熄火后及时交还声音 | 以前放着音乐熄火，原车收音机或媒体可能约 3 分钟没声音；现在几秒内恢复 |
| 仪表地图更稳 | 同时开着中控上的地图卡片时，仪表地图偶尔卡顿或出不来的情况更少 |
| 冷启动偶尔更快出画面 | 少数情况下连上后要多等 1–2 秒才出画面，这一步省掉了 |
| 高通低延迟解码出问题时只出一次 | 打开「高通低延迟解码」的人，同一次连接里不会在仪表上再卡一次 |
| 有线连接更轻 | 有线连接不再在后台采集手机日志，用起来没有区别 |
| 诊断报告更准 | 只影响排查问题 |

### v148：新增「未导航时也显示仪表地图」（实验性）

打开后，CarPlay 连上、没有导航路线时，仪表也显示 CarPlay 地图。开始导航不会把它收起，导航结束后地图也继续保留。

## 二、安装

1. 停车状态下安装 v148 安装包，**直接覆盖安装，不要先卸载**，否则设置和连接信息会丢失。
2. 安装包内带 CarPlay 认证文件，请勿转发给他人。
3. 装好后打开 DiPlay，确认能正常连上 CarPlay。

## 三、上车前要打开的开关

### 车机方向盘菜单

| 设置 | 选择 | 为什么 |
| --- | --- | --- |
| 导航显示模式 | **小屏导航** 或 **全屏导航** | 选「关闭」或「导航时开启」时仪表只显示箭头，iPhone 不会发地图，后面的仪表测试就做不了 |

### DiPlay 设置

| 位置 | 开关 | 建议 | 测什么 |
| --- | --- | --- | --- |
| 设置 → 导航 → 亿咖通导航 | 开始导航时自动显示仪表地图 | **打开** | 仪表地图 |
| 设置 → 导航 → 亿咖通导航 | 未导航时也显示仪表地图（实验性） | **打开**（v148 新增） | 巡航时的仪表地图 |
| 设置 → 导航 → 亿咖通导航 | HUD／仪表导航提示 | 保持现状 | 箭头、距离、车道 |
| 设置 → 导航 → 亿咖通导航 | 在车机桌面显示 CarPlay 地图 | 测第 4 步时打开 | 中控地图卡片 |
| 设置 → 高级 → 视频与音频 | 流畅视频（实验性） | 只在第 5 步打开，测完关掉 | 主屏画面延迟 |
| 设置 → 高级 → 视频与音频 | 高效视频（HEVC） | 可选，开关各测一轮更好 | 仪表地图稳定性 |
| 设置 → 高级 → 视频与音频 | 高通低延迟解码（实验性） | 保持现状 | 不需要专门测 |

> 打开「流畅视频」会重新连接一次 CarPlay，触控会稍微变慢，这是正常现象。

## 四、测试步骤

每一步后面的方框，测完打勾或写下看到的情况。遇到问题**先保存诊断报告，再重试**，并记下大概时间。

### 1. 冷启动（重复 2–3 次）

上车启动，等 DiPlay 自动连上 CarPlay。

- [ ] 能自动连上并出画面
- [ ] 出画面大约用了多久：____ 秒

### 2. 巡航时的仪表地图（v148 新功能）

连上后**不要开始导航**，正常开一段路。

- [ ] 仪表上出现了 CarPlay 地图
- [ ] 地图会跟着车走（静止或北向上时地图可能隔几秒才动一下，属于正常）
- [ ] 用方向盘或仪表上的操作隐藏地图，能收起；再显示，能恢复
- [ ] 在 DiPlay 里关掉「未导航时也显示仪表地图」，仪表立即回到原车画面；再打开能恢复

| --- | --- |

| 苹果地图（地图设置里选「车头向上」） | |

### 3. 导航

在 CarPlay 里开始一条导航。

- [ ] 仪表出现地图，没有闪黑或重新加载
- [ ] 仪表上的箭头、距离、路名正常
- [ ] 结束导航后，仪表地图**仍然保留**（v148），箭头和距离消失
- [ ] 再开始一条新导航，一切正常

**请拍一张导航中的仪表照片**：我们想看导航卡片和地图里的转向提示有没有重复、有没有挡住地图。

### 4. 中控地图卡片

导航进行中，打开「在车机桌面显示 CarPlay 地图」。

- [ ] 中控卡片出现地图，方向、颜色、比例和以前一样
- [ ] 仪表地图没有因此变卡
- [ ] 关掉再打开卡片 2–3 次，仪表地图始终正常

### 5. 流畅视频

打开「流畅视频」，等 CarPlay 重新连上，在主屏上左右滑动约 1 分钟。

- [ ] 画面正常，没有花屏、卡住
- [ ] 测完把「流畅视频」关掉

### 6. 熄火

一边放音乐一边熄火，几秒后用原车收音机或媒体试一下。

- [ ] 熄火后几秒内原车能出声（以前要等约 3 分钟）
- [ ] 再上电后 CarPlay 自动重连，音乐和导航播报都正常

### 7. 有线连接（方便时再测）

- [ ] 插线能正常连上，有画面、有声音

## 五、测完要发回来的东西

1. **诊断报告**：在 **设置 → 诊断 → 保存诊断报告** 导出。最好在开了 20 分钟左右、做完第 2–4 步后导出一次。
2. **仪表照片**：巡航时一张、导航时一张。
3. **上面的勾选结果**，以及发现问题的大概时间。

## 六、已知情况

- 「未导航时也显示仪表地图」是实验功能，**默认关闭**。各家手机地图在没有路线时往仪表画什么，我们还没有在本车验证，这正是这轮要确认的事。
- 苹果地图没有路线时，只在画面变化时才更新仪表画面，停车时地图看起来像静止的。
- 关掉「HUD／仪表导航提示」，仪表上的导航卡片会消失，HUD 上的提示也会一起消失；目前没办法只关其中一个。
- 打开巡航地图后，仪表整趟行车都在显示 CarPlay 地图，会盖住仪表原本没导航时的内容（比如媒体卡片）。不需要时在设置里关掉即可。
