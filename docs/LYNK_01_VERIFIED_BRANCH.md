以及 USB 部分读取保持、等待信任、拒绝/锁定/超时/取消分类、终止结果提示与重试保护；
截图测试覆盖紧凑简体/繁体中文、完整英文，以及 RTL 系统上的英文回退，均使用大字体。
这些是软件证据，不替代新分支 APK 的实车回归。

完整检查遵循本分支 `AGENTS.md` 与 `.github/workflows/android.yml`；

## 应用界面语言精简

按用户后续要求，应用界面仅保留英文默认资源、简体中文和繁体中文；语言选择器及
Android 应用语言声明同步收窄，保留“跟随系统”。不支持的系统语言使用默认英文资源。
删除原阿拉伯语、俄语、西班牙语、乌克兰语、日语、意大利语资源及其专用翻译测试；
保留通用 RTL 布局能力，并以 RTL 系统上的英文回退截图继续检查布局，不将无阿语翻译等同无 RTL 环境。
历史 README/文档不在本次界面语言精简范围内。语言精简是本次明确维护要求，不另称已有实车验证。
