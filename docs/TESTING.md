# 领克车机测试

当前验收目标为领克 ECARX 车机 Android 9 / API 28。默认检查聚焦仪表媒体与封面、导航、USB、内置热点、音频、方控和 Siri / HiCar 诊断，不要求其他 Android 版本、电视、MTK 或示例应用回归。

自动化入口与范围见 [ECARX 软件测试](ECARX_TESTING.md)，测试替身和协议样本见 [夹具索引](ECARX_FIXTURES.md)。实车测试在停车状态下进行，使用本次构建与同一部 iPhone；记录车机固件、APK 版本、iOS 版本、连接方式和操作时间。

## 本次实车验收

| 项目 | 操作与通过条件 | 收集的信息 |
| --- | --- | --- |
| 仪表封面 | 连上 CarPlay 播放带封面的歌曲，换歌、暂停、恢复、切换音乐应用，再断连重连。音乐卡片显示对应封面；换歌和断连无旧图残留 | 封面接收/解码、HTTP 发布/请求/成功取图次数，仪表照片 |
| USB | 从未连接状态插入 iPhone，确认系统授权；分别测试同意、拒绝后重试、拔插、从无线切到有线。授权弹窗能完成，成功后进入数据通信 | 请求/结果设备节点、自动确认次数与时间、枚举阶段、接口 claim、queue 与旧 API 回退记录 |
| 内置热点 | 选择车载热点模式，完成现有系统设置权限或 ADB 授权并显式开启自动控制。关闭热点后打开 DiPlay，确认热点实际广播且 iPhone 能连接；再测试无授权、启动失败及重连 | 直接启动能力、权限状态、启动尝试与系统返回、实际热点状态；日志不含密码 |
| 音频 | 有线和热点各播放音乐，插入导航播报、暂停/恢复并持续播放；检查采样率、音调、速度与播报衰减，随后测试 Siri 麦克风和通话 | 音频格式、缓冲/时钟修正、焦点和麦克风日志，异常发生时间 |
| 导航与系统栏 | 连续导航，检查转向/车道、到达及断连清空；进入和退出设置、重连，确认系统导航条与触摸正常 | 仪表与主屏照片、显示尺寸、导航输出和生命周期日志 |
| 方控 / HiCar | 记录音量按钮短按和长按在未连接、已连接 CarPlay 时的行为；导出报告，保留系统原有 HiCar 行为 | 按键事件/配对、HiCar 可见包/启用状态/平台签名/权限与 Siri 接管前置条件 |

HiCar 本次仅收集只读诊断，不停用系统应用，不视为已经实现长按键接管。软件夹具通过也不能证明 OEM 封面取图、USB 驱动或热点广播已在实车通过。

## 导出与反馈

从设置中的诊断入口保存报告。Android 9 缺少文档选择器时应能保存到应用的 `diagnostic-reports` 目录，并可查看或分享；连续导出不得覆盖前一份。先复现、再立即导出，附上操作时间和照片；提交前检查报告中的个人信息。不要把 APK、原始个人日志、授权密钥或设备缓存作为测试夹具提交。

仅当实际修改涉及其他连接方式、平台或示例应用时，再扩展对应测试范围，不把历史兼容性矩阵作为本车机的每次构建要求。
